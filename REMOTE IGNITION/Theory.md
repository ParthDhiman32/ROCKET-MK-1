# Remote Ignition System 
This is a isolated remote ignition system which will be used for remotely igniting the rocket motor of rocket mk-1 from a safe distance 

# Working 
This system will recivee a binary signal from the ground station via a physical button which it will then transfer to the reciever pact of the system which is connected to 
a relay which is connected to a 12V high current battery which is connected to a rocket motor igniter which hence sets fire to the rocket's motor 

# PCB 
I will not be designing the entire system from scratch to as any single faliure in the pcb could be costly so i will be simply attaching the FS1000A 433mHz Tx and Rx modules to the pcb's and then 
using them as the main systems 
the transmitter pcb is not required but the reciever'sn pcb is required as it encorporates a relay and battery connectors
